# Curadoria Editorial Local

Esta pasta guarda a base editorial do BuzzPop no seu computador. Ela nao esta preparada para subir ao GitHub agora.

Use aqui para organizar:

- sites que podem servir como fonte de noticias;
- regras para reescrever noticias com linguagem propria;
- exemplos de textos que definem o tom do BuzzPop;
- rascunhos de noticias antes de entrarem no site;
- ideias de categorias, tags e formatos.

## Estrutura

```txt
local-curadoria/
  fontes/
    sites.md
  linguagem/
    guia-editorial.md
    exemplos-para-estudo.md
  noticias/
    pauta-modelo.md
```

## Como vamos usar

1. Voce me passa os sites fonte.
2. A gente registra o que pode ser puxado de cada site.
3. Voce me passa exemplos do estilo de escrita que quer usar.
4. A gente transforma isso num guia editorial do BuzzPop.
5. Depois conectamos o site a essa logica de curadoria e reescrita.

Observacao: "treinar" aqui, por enquanto, significa montar instrucoes, exemplos e regras para guiar a reescrita. Nao precisamos criar um agente novo agora.
