BuzzPop: regras, bloqueios e fluxo de publicacao

Este documento explica, de forma simples, por que uma materia pode ser rejeitada antes de entrar no site. A ideia e que o sistema seja rigido nos pontos que podem deixar o site com cara de rascunho, curadoria automatica ou copia de fonte.

Resumo em uma frase: a materia so publica se parecer noticia final para leitor, tiver tamanho minimo, titulo bom, imagem com origem coerente e nenhum texto de bastidor.

1. Mapa simples do fluxo

Etapa O que acontece Arquivo principal
1. Coleta O sistema busca noticias recentes e monta uma lista bruta de assuntos. data/news.json
2. Escolha Seleciona candidatos de entretenimento, TV, famosos, cinema, streaming, musica e cultura pop. scripts/hybrid-refresh.js
3. Escrita com IA A OpenAI escreve titulo, chamada, corpo, editoria, tags e sugestao de imagem. scripts/lib/editorial-drafts.js
4. Revisao automatica O proprio gerador verifica se o texto ficou curto, generico, copiado ou com linguagem interna. revisao factual em scripts/lib/editorial-drafts.js
5. Rejeicao antes de publicar Se uma materia falha, ela e pulada. O sistema tenta a proxima noticia. generateEditorialDrafts() em scripts/lib/editorial-drafts.js
6. Validador final Antes de gerar site, outro validador confere todas as materias finais. scripts/validate-articles.cjs
7. Site final So se tudo passar, gera HTML final e copia para GitHub Pages. scripts/generate-final-site.cjs e docs/

2. Comandos importantes

Comando Para que serve O que bloqueia
npm run hybrid:refresh Atualiza noticias, escreve materias e valida. Bloqueia se nenhuma materia boa passar ou se o arquivo final reprovar.
npm run validate:articles Confere data/articles.json, que alimenta o Pages. Bloqueia textos ruins, curtos, titulo ruim e imagem incoerente.
npm run site:final Gera o HTML em public/final-site. Roda validate:articles antes. Se reprovar, nao gera.
npm run site:gh-pages Copia o site final para docs/, que e o GitHub Pages. Roda validate:articles antes. Se reprovar, nao publica.

3. Regras que fazem uma materia reprovar

3.1 Tamanho minimo

RegraFaixa atualPor que existe
Palavras 45 a 260 Permite nota curta sem obrigar a IA a preencher espaco.
Paragrafos 2 a 5 Mantem leitura clara e proporcional aos fatos disponiveis.

O texto deve parar quando os fatos acabarem. Se nao houver material para 45 palavras sem repeticao ou invencao, a pauta deve ser rejeitada.

3.2 Titulo

RegraReprova quandoExemplo ruim
Titulo longo demais Passa de 95 caracteres. Um titulo que tenta contar a materia inteira.
Titulo incompleto Termina com "de", "da", "do", "em", "para", "por". Ator fala sobre bastidor de
Titulo truncado Contem reticencias. Famosa revela...
Titulo generico Usa formula vazia. tem nova atualizacao, movimenta debate no cinema
Titulo parecido com RSS Fica parecido demais com o titulo coletado da fonte. Copiar ou parafrasear quase igual a fonte original.

3.3 Linguagem interna proibida

O corpo da materia nao pode parecer explicacao do sistema. Ele precisa parecer noticia publicada para leitor final.

Tipo de erroExpressao bloqueadaPor que reprova
Curadoria aparecendo curadoria, ranking, pauta, rodada Mostra bastidor editorial que o leitor nao deveria ver.
Automacao aparecendo sistema, algoritmo, mesa automatica, Google Trends Faz a materia parecer relatorio, nao noticia.
Justificativa de escolha selecionado automaticamente, quantidade de fontes, cruzar sinais Explica por que a materia foi escolhida, em vez de contar o fato.
Texto de projeto rascunho de WordPress, rotina pode rodar por cron, para quem administra o site Isso e documentacao interna, nao materia publica.
Ruim: "A selecao entrou no BuzzPop porque apareceu em 5 fontes diferentes."
Bom: "A serie voltou a chamar atencao apos novos detalhes sobre o personagem vivido pelo ator."

3.4 Imagem

RegraReprova quandoMotivo
Precisa ter imagem Campo image vazio. A home depende da imagem para o layout.
Credito nao pode ser generico Credito contem busca automatica. O leitor precisa ver uma origem minimamente clara.
Imagem externa precisa de origem Imagem vem de URL externa e nao tem imagePostUrl. Sem origem, nao da para auditar de onde veio.
Credito precisa bater com a origem Credito diz um site, mas a URL da imagem vem de outro. Evita erro como dizer "Noticia da TV" quando a imagem veio de outro dominio.
Nao usar a fonte da noticia Imagem vem do mesmo site que publicou a materia usada como fonte. Evita copiar exatamente a imagem da noticia original.

4. O que acontece quando uma materia falha

  1. A OpenAI escreve a primeira versao.
  2. O gerador verifica se ha problema.
  3. Se houver problema, pede uma reparacao para a OpenAI.
  4. Se ainda falhar, a materia e rejeitada antes de entrar no site.
  5. O sistema tenta a proxima noticia da lista.
  6. No final, validate:articles confere tudo novamente.
  7. Se qualquer materia final falhar, o site nao e gerado/publicado.

5. Como ler uma mensagem de erro

MensagemTraducao simplesComo resolver
38/45 palavras As evidencias nao sustentaram nem uma nota curta. Buscar mais fontes ou rejeitar; nunca completar com texto generico.
titulo generico ou incoerente O titulo usou formula vazia. Gerar titulo novo, direto e com fato real.
linguagem interna ou bastidor editorial O texto falou como sistema, nao como noticia. Remover explicacao de selecao, ranking, fontes e automacao.
credito da imagem nao bate O credito nao corresponde ao dominio real. Trocar imagem ou corrigir credito/origem.
imagem vem de fonte da noticia A imagem veio do mesmo site usado como fonte. Buscar imagem ilustrativa em outro lugar seguro.

6. Fluxo ideal para trabalharmos daqui em diante

  1. Rodar npm run hybrid:refresh.
  2. Se reprovar, ler os erros e classificar: texto, titulo ou imagem.
  3. Se for texto curto, reforcar o prompt de escrita/reparo.
  4. Se for titulo ruim, ajustar regras de titulo em scripts/lib/editorial-drafts.js.
  5. Se for imagem, ajustar scripts/lib/illustrative-images.js ou o mapeamento de fontes.
  6. Quando passar, rodar npm run site:final.
  7. Depois rodar npm run site:gh-pages.
  8. Testar a home e os links das materias.
  9. Fazer commit e push.

8. Regra principal para nao esquecer

Tudo que for processo fica invisivel para o leitor. A automacao pode usar ranking, fontes, Trends, OpenAI e validadores. Mas o texto publicado precisa se comportar como materia jornalistica final.
