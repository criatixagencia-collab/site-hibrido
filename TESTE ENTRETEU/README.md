# Teste Entreteu

Protótipo isolado de um portal de notícias de entretenimento com a marca Entreteu.

## Abrir

Abra `index.html` diretamente no navegador ou execute:

```bash
python3 -m http.server 4180 --directory "TESTE ENTRETEU"
```

O protótipo não altera nem participa da geração do site BuzzPop.

## Laboratório de marca

Abra `logo-lab.html` para comparar variações de logo e identidade visual do Entreteu.
